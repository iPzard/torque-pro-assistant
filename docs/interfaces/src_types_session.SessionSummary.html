    Interface SessionSummary

    Aggregate metrics derived from a session's row data. Produced by summarize in utils/summarize/. Numbers are imperial units (mph / lb·ft / °F / psi / mpg / miles) per the design's Library defaults; the renderer converts at display time when units mode is metric.
